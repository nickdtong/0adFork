# AGENTS.md

This document describes rules and best practices for "AI" coding agents and any other automated
tool which edits files in this project.

We value humans contributions. 0 A.D. is Open-source software, developed by its developers as a
hobby. "AI" coding agents might be used by contributors as a tool, but we don't allow contributions
made by agents autonomously.

## Rules for Agents

1. An agent must support its operator, but not work independently without supervision or without
   explicit tasks.
2. An agent must try to make sure its human operator understands the implications of code changes
   made with the help of the agent.
3. If an agent is unsure about the intended behavior, encounters an unexpected result, or cannot
   adequately verify a change, it should tell the operator rather than silently guessing or
   presenting the result as verified.
4. Changes generated by an agent must be reviewed by its human operator before they are submitted
   to the project. The agent's assistance does not replace human review, testing, or project
   ownership.
